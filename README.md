# تحويل العملة — Currency Converter

تطبيق ويب تقدّمي (PWA) لتحويل الليرة السورية (القديمة والجديدة) مقابل العملات العالمية والذهب،
يعمل بدون إنترنت ويخزّن الأسعار محلياً على الجهاز.

## الميزات

- تحويل فوري بين الليرة السورية (قديمة/جديدة) والدولار واليورو وعملات أخرى، مع سعري شراء ومبيع.
- حاسبة ذكية داخل حقل المبلغ (مثل `500+250` أو `100*3`).
- سلة مبالغ متعددة بعملات مختلفة مع إجمالي فوري وإيصال قابل للنسخ أو المشاركة عبر واتساب.
- تسعير بضائع مع هامش ربح مئوي وحساب سعر البيع بأي عملة.
- أسعار مباشرة من ملف `public/rates.json` مع تحديث تلقائي عبر GitHub Actions كل ساعة.
- ثلاث لغات: العربية، الإنجليزية، الألمانية. وضعان: فاتح وداكن.
- يعمل بالكامل دون خادم خلفي ودون اتصال بالإنترنت بعد أول تحميل.

## التشغيل محلياً

يتطلب Node.js 20+ (أو Bun):

```sh
npm install
npm run dev
```

## البناء للإنتاج

```sh
npm run build
npm start   # يشغّل خادم Node من .output
```

## تحديث أسعار الصرف تلقائياً

يحدّث سير العمل `.github/workflows/update-rates.yml` ملف `public/rates.json` كل ساعة
عبر GitHub Actions (مجاني للمستودعات العامة). لضبط سعر الدولار يدوياً:
أضف في إعدادات المستودع **Settings → Secrets and variables → Actions → Variables**
المتغير `USD_SYP_NEW` بقيمة سعر الدولار بالليرة الجديدة، و`SPREAD` لنسبة الفرق بين الشراء والمبيع.
